WHY THE NAIVE RENDERER FLICKERS:

Standard Arduino/embedded tutorials call lcd.clear() before printing new text. The HD44780 clear command blanks all DDRAM for 1.52 ms, followed by a slow 32.0 ms sequential rewrite over I2C. The human eye detects this periodic 100% luminance drop as annoying visible strobe flash.
